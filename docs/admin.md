# Админка Printopus

Админка доступна по адресу `/admin`. Публичные страницы и API оформления заказов не требуют входа; заказы, контакты клиентов и изменение цен закрыты серверной сессией.

## Настройка доступа

В окружении должны быть заданы:

- `ADMIN_USERNAME` — логин менеджера;
- `ADMIN_PASSWORD` — пароль;
- `ADMIN_SESSION_SECRET` — случайная строка длиной не менее 32 символов для подписи сессии.

Значения из `.env.example` нельзя использовать в production. Production-сайт должен работать только по HTTPS.

## Возможности

- сводка по заказам, сумме и товарам;
- поиск заказов по номеру, имени или телефону;
- фильтр по статусам и постраничный просмотр;
- карточка заказа с контактами, получением, составом, распределением размеров и расчётом;
- смена статуса с комментарием и постоянной историей;
- журнал действий менеджера;
- изменение товаров, базовых цен и доступности;
- изменение цветов, размеров и доплат;
- управление способами печати, форматами и скидками;
- добавление новых вариантов, способов печати, форматов и уровней скидки.
- просмотр и безопасное скачивание загруженных макетов из карточки заказа.
- состояние доставки уведомления в Telegram и ручной повтор после исчерпания автоматических попыток.

Изменения каталога сразу выдаются через публичный `/api/catalog` и используются главной страницей и конструктором. Финальная цена заказа всё равно повторно рассчитывается сервером.

## Защита

Сессия подписана, хранится в `HttpOnly` cookie и действует восемь часов. Изменяющие запросы проверяют origin, а форма входа ограничивает повторные неудачные попытки. Все изменения статусов и каталога записываются в `admin_audit_log`.

API разрешает только переход на соседний этап, возврат на один этап с обязательной причиной, отмену с причиной и возобновление отменённого заказа как нового. Telegram использует только последовательные переходы вперёд.

Production-конфигурация ограничивает размер входящего запроса на Caddy, держит PostgreSQL и приложение в закрытой сети и хранит макеты в `/srv/printopus/uploads`. Базу и этот каталог необходимо резервировать вместе по инструкции `docs/vps.md`.
